# Daniel Mladek — Portfolio

My personal portfolio, built with React, TypeScript and Vite.

## Development

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Vite automatically processes Tailwind and CSS changes during development.

## Production build

```sh
npm run build
```

The generated site is saved to `dist/`. Run `npm run preview` to preview the build locally.
