# Daniel Mladek — Portfolio

My personal portfolio, built with React, TypeScript and Vite.

## Development

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To rebuild styles automatically while developing, run `npm run watch:css` in a separate terminal.

## Production build

```sh
npm run build:css
npm run build
```

The generated site is saved to `dist/`. Run `npm run preview` to preview the build locally.
